# Glossary

| Term | Meaning |
| --- | --- |
| **Primary XML** | Compiler XML documentation whose members are part of the generated documentation set. |
| **Reference XML** | XML documentation loaded for inheritance/reference resolution without creating primary pages. |
| **Aggregate model** | One Core model created from multiple primary XML inputs through `Xml2Doc.LoadAggregate`. |
| **Aggregation owner** | The single MSBuild project that renders a repository-level multi-project documentation set. |
| **`Xml2Doc_AggregateXml`** | Explicit MSBuild primary XML item added to repository aggregation. |
| **`Xml2Doc_ReferenceXml`** | Explicit MSBuild reference-only XML item. |
| **Per-type mode** | Output mode that writes one Markdown file per documented type plus optional index/namespace output. |
| **Single-file mode** | Output mode that writes the full documentation set into one Markdown file. |
| **RendererOptions** | Core configuration object controlling output shape and rendering services. |
| **RendererRunner** | Core pipeline coordinator for planning and rendering execution. |
| **Manifest identity** | Stable invocation identity used to authorize stale-output ownership and pruning. |
| **Output ledger** | MSBuild list of files generated by a successful invocation, used to detect missing outputs. |
| **Fingerprint** | Incremental state derived from relevant inputs/options so MSBuild can decide whether generation is current. |
| **Structured diagnostic** | Diagnostic with stable `XML2DOC###` identity, severity, message, and optional context. |
| **Anchor algorithm** | Strategy used to generate Markdown anchors and matching internal link fragments. |
| **Auto-linking** | Optional rendering behavior that links recognized symbols in safe free-text locations. |
| **Alias provider** | Replaceable service for displaying type aliases/names. |
| **External symbol resolver** | Replaceable service for links that cannot be resolved inside the generated documentation set. |
| **Template renderer** | Replaceable service/file template used to wrap rendered document content. |
| **`XML2DOC006`** | Duplicate documentation-member ownership across primary aggregate XML inputs. |
| **`XML2DOC007`** | Conflicting MSBuild ownership of an aggregate `index.md`. |
| **Deterministic output** | Output whose ordering and bytes remain stable for equivalent inputs/options under supported hosts and schedules. |
