# LineEndingStyle

Controls the line-ending sequence used in rendered Markdown.

<a id="xml2doc.core.lineendingstyle.crlf"></a>

## Field: CrLf

Use carriage return followed by line feed (`\r\n`).

<a id="xml2doc.core.lineendingstyle.lf"></a>

## Field: Lf

Use line feed (`\n`) on every platform.

<a id="xml2doc.core.lineendingstyle.native"></a>

## Field: Native

Use [NewLine](System.Environment.md#system.environment.newline) for the current host.
