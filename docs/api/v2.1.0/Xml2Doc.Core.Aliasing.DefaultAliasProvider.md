# DefaultAliasProvider

Applies the built-in C# keyword aliases for framework type tokens.

<a id="xml2doc.core.aliasing.defaultaliasprovider.applyaliases(string)"></a>

## Method: ApplyAliases(string)

Applies aliases to complete type tokens without modifying partial identifiers.

**Parameters**

- `value` — The signature, label, or documentation identifier to transform.

**Returns**

The transformed value.
