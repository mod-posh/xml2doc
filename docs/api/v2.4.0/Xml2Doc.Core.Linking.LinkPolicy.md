# LinkPolicy

Controls how unresolved XML documentation links are routed.

<a id="xml2doc.core.linking.linkpolicy.internalonly"></a>

## Field: InternalOnly

Preserve the existing internal-link behavior for every cref.

<a id="xml2doc.core.linking.linkpolicy.preferexternalforunknown"></a>

## Field: PreferExternalForUnknown

Prefer a configured external resolver when the cref is not part of the rendered documentation model.
