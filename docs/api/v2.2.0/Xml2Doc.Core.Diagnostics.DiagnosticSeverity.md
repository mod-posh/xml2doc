# DiagnosticSeverity

Identifies the impact of an Xml2Doc diagnostic.

<a id="xml2doc.core.diagnostics.diagnosticseverity.error"></a>

## Field: Error

A condition that prevents successful processing.

<a id="xml2doc.core.diagnostics.diagnosticseverity.info"></a>

## Field: Info

Informational context that does not require action.

<a id="xml2doc.core.diagnostics.diagnosticseverity.warning"></a>

## Field: Warning

A non-fatal condition that may require attention.
