# DiagnosticIds

Stable identifiers emitted by Xml2Doc diagnostics.

<a id="xml2doc.core.diagnostics.diagnosticids.conflictingindexownership"></a>

## Field: ConflictingIndexOwnership

Multiple MSBuild projects claim ownership of the same generated index.

<a id="xml2doc.core.diagnostics.diagnosticids.duplicateanchor"></a>

## Field: DuplicateAnchor

Multiple documented symbols generated the same anchor.

<a id="xml2doc.core.diagnostics.diagnosticids.duplicateinputmember"></a>

## Field: DuplicateInputMember

Multiple XML documentation inputs define the same member.

<a id="xml2doc.core.diagnostics.diagnosticids.malformedxml"></a>

## Field: MalformedXml

An XML documentation input was malformed.

<a id="xml2doc.core.diagnostics.diagnosticids.missingsummary"></a>

## Field: MissingSummary

A documented symbol does not contain a summary.

<a id="xml2doc.core.diagnostics.diagnosticids.unresolvedcref"></a>

## Field: UnresolvedCref

An XML documentation cref could not be resolved.

<a id="xml2doc.core.diagnostics.diagnosticids.unresolvedinheritdoc"></a>

## Field: UnresolvedInheritDoc

An inheritdoc target could not be resolved.
