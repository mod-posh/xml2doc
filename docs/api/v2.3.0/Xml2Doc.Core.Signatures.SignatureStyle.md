# SignatureStyle

Controls optional detail in rendered member signatures.

<a id="xml2doc.core.signatures.signaturestyle.#ctor(bool,bool,bool)"></a>

## Method: #ctor(bool, bool, bool)

Controls optional detail in rendered member signatures.

**Parameters**

- `IncludeParamNames` — Include documented parameter names.
- `IncludeConstraints` — Include available generic parameter constraints and use documented type-parameter names instead of generated placeholders so each `where` clause matches its signature.
- `IncludeDefaultValues` — Include available parameter default values.

<a id="xml2doc.core.signatures.signaturestyle.default"></a>
