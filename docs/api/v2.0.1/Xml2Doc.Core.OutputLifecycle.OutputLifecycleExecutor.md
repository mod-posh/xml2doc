# OutputLifecycleExecutor

Applies a validated output lifecycle plan after output generation succeeds.

<a id="xml2doc.core.outputlifecycle.outputlifecycleexecutor.executeaftersuccessfulgeneration(xml2doc.core.outputlifecycle.outputmanifestlocation,system.collections.generic.ireadonlylist[string],bool)"></a>

## Method: ExecuteAfterSuccessfulGeneration(OutputManifestLocation, IReadOnlyList<string>, bool)

Plans and optionally applies stale-output cleanup for a successful generation.

**Parameters**

- `location` — The invocation-scoped manifest location.
- `generatedFiles` — The complete output-root-relative file set generated by the invocation.
- `dryRun` — to return the plan without changing files or ownership.

**Returns**

The deterministic lifecycle plan.
